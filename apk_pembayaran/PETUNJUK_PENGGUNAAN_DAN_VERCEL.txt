ISI PAKET INI:
1. index.html & folder assets/ -> Web build utama siap hosting (Vercel / Netlify / cPanel).
2. al-mumtaz-finance-offline-single-file.html -> File HTML mandiri (bisa langsung di-double click tanpa server).
3. vercel.json -> Konfigurasi otomatis untuk routing Vercel SPA (tanpa error 404 saat refresh).
4. _redirects -> Konfigurasi untuk Netlify SPA.

CARA HOSTING DI VERCEL (GRATIS):
1. Buka vercel.com lalu login.
2. Unggah isi folder ini atau hubungkan repositori GitHub Anda.
3. Vercel akan otomatis mengenali framework Vite dan file vercel.json.
4. Klik 'Deploy'. Dalam 1 menit website keuangan Anda sudah aktif online dengan HTTPS!
